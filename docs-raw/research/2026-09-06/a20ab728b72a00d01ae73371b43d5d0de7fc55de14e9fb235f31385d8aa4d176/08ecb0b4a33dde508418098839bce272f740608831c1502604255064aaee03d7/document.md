# Tag Values

## Topics

### Media Type

Values for use with the tag media type category.

[`kCMTagMediaTypeVideo`](/documentation/CoreMedia/kCMTagMediaTypeVideo)

A value for associating a tag’s media type with video.

[`kCMTagMediaTypeAudio`](/documentation/CoreMedia/kCMTagMediaTypeAudio)

A value for associating a tag’s media type with audio.

[`kCMTagMediaTypeMetadata`](/documentation/CoreMedia/kCMTagMediaTypeMetadata)

A value for associating a tag’s media type with metadata.

### Media Subtype

Values for use with the tag media subtype category.

[`kCMTagMediaSubTypeMebx`](/documentation/CoreMedia/kCMTagMediaSubTypeMebx)

### Frame Arrangements

Values for use with the tag frame-packing information category.

[`kCMTagPackingTypeNone`](/documentation/CoreMedia/kCMTagPackingTypeNone)

A frame-packing tag value for video without packed frames.

[`kCMTagPackingTypeSideBySide`](/documentation/CoreMedia/kCMTagPackingTypeSideBySide)

A tag stating that associated video has packed frames with a left eye image on the left and right eye image on the right.

[`kCMTagPackingTypeOverUnder`](/documentation/CoreMedia/kCMTagPackingTypeOverUnder)

A tag stating that associated video has packed frames with a left eye image on the top and right eye image on the bottom.

### Projection Surfaces

Values for use with the tag projection type category.

[`kCMTagProjectionTypeRectangular`](/documentation/CoreMedia/kCMTagProjectionTypeRectangular)

A value for projection tags indicating that display is on a flat rectangular surface.

[`kCMTagProjectionTypeEquirectangular`](/documentation/CoreMedia/kCMTagProjectionTypeEquirectangular)

A value for projection tags indicating that display is on a 360 degree equirectangular projection.

[`kCMTagProjectionTypeFisheye`](/documentation/CoreMedia/kCMTagProjectionTypeFisheye)

Video content displays as a fisheye projection.

### 3D Video Data

Values for use with the tag categories that provide stereo video metadata.

[`kCMTagStereoInterpretationOrderReversed`](/documentation/CoreMedia/kCMTagStereoInterpretationOrderReversed)

A value for a stereo interpretation tag indicating the video data for the left and right eyes are reversed.

[`kCMTagStereoLeftAndRightEye`](/documentation/CoreMedia/kCMTagStereoLeftAndRightEye)

A value for a stereo tag indicating the video track has left and right eye layers.

[`kCMTagStereoLeftEye`](/documentation/CoreMedia/kCMTagStereoLeftEye)

A value for a stereo tag indicating the video track has a left eye layer.

[`kCMTagStereoRightEye`](/documentation/CoreMedia/kCMTagStereoRightEye)

A value for a stereo tag indicating the video track has a right eye layer.

[`kCMTagStereoNone`](/documentation/CoreMedia/kCMTagStereoNone)

A value for a stereo tag indicating the video track has no eye layer data.
