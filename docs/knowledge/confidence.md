# 可信度与人工审核

高：匹配官方依据、适用性明确、推论前提完整，独立审查确认，无关键未决缺口。
中：有官方依据，但条件解释、映射或推论仍有明确不确定性。
低：必答结论未知、适用性未知、关键资料缺失或冲突，或缺少必需的运行观测。

代码逐项检查评级上限，整体取全部必答结论最低档。比较不能高于最弱关键前提。不能删掉必答问题、平均评分或在自由正文里增加未评级断言。已知错误/虚构证据必须返工，不能降为低可信后发布。

每项评级绑定 claim_hash 与 input_fingerprint；后者还固定共同研究规格、证据、独立审查、来源、基线、绑定和政策。任何相关内容变化都要重新评定。历史评级原值保留，失效知识退出默认可信结果集。

低可信知识可见、可检索，审核按文章内容版本归组、逐结论裁决。状态为 pending/in_review/decided/research_requested/deferred。支持补充证据、修正、指定阶段重研、接受限制及仍无法判断。每次动作记录操作人、理由、内容指纹及幂等键。接受限制不自动提高可信度，同版本已处理结论不会重新成为 pending。

人工指出错误的结论指纹留在追加审核历史中，回滚不能清除。人工裁决和正式发布在同一审核锁顺序下校验；准备后出现新裁决，提交拒绝旧投影并要求重新准备。

真机需求与置信度独立。模型/文档/人工确认不算真实设备结果。运行材料必须单独导入验证后才能引用；没有材料时保留缺口，不能填写虚构 runtime_evidence_refs。
