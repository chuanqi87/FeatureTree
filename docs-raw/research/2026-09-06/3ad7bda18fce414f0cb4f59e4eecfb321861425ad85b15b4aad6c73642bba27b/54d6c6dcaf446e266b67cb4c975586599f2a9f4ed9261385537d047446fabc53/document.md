# Button Icons

Icons that indicate the function of a button.

## Overview

Button icons are badges that are added to a `button` element as a visual clue to
what the button is used for.

### button-add

The resource name for the add button icon is `button-add`. Place an add button icon
next to content to indicate that the user can add the item. Place the add icon using
`<badge src="resource://button-add" />`.

![A white plus sign inside a black-filled circle.](images/com.apple.TVML/button-icons-1.png)
