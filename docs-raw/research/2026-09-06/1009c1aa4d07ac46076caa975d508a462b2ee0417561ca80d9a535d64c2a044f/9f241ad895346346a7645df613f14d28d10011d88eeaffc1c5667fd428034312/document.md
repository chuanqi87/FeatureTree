# Audio Output Routes

The various audio output destinations available for an iOS device.

## Discussion

These strings are used as values for the [`kAudioSession_AudioRouteKey_Type`](/documentation/AudioToolbox/kAudioSession_AudioRouteKey_Type) key for the dictionary associated with the [`kAudioSession_AudioRouteKey_Outputs`](/documentation/AudioToolbox/kAudioSession_AudioRouteKey_Outputs) array.

## Topics

### Constants

[`kAudioSessionOutputRoute_LineOut`](/documentation/AudioToolbox/kAudioSessionOutputRoute_LineOut)

Analog line-level output.

[`kAudioSessionOutputRoute_Headphones`](/documentation/AudioToolbox/kAudioSessionOutputRoute_Headphones)

Speakers in headphones or in a headset.

[`kAudioSessionOutputRoute_BluetoothHFP`](/documentation/AudioToolbox/kAudioSessionOutputRoute_BluetoothHFP)

Speakers that are part of a Bluetooth Hands-Free Profile (HFP) accessory.

[`kAudioSessionOutputRoute_BluetoothA2DP`](/documentation/AudioToolbox/kAudioSessionOutputRoute_BluetoothA2DP)

Speakers in a Bluetooth A2DP device.

[`kAudioSessionOutputRoute_BuiltInReceiver`](/documentation/AudioToolbox/kAudioSessionOutputRoute_BuiltInReceiver)

The built-in speaker you hold to your ear when on a phone call.

[`kAudioSessionOutputRoute_BuiltInSpeaker`](/documentation/AudioToolbox/kAudioSessionOutputRoute_BuiltInSpeaker)

The primary built-in speaker.

[`kAudioSessionOutputRoute_USBAudio`](/documentation/AudioToolbox/kAudioSessionOutputRoute_USBAudio)

Speaker(s) in a Universal Serial Bus (USB) accessory, accessed through the device 30-pin connector.

[`kAudioSessionOutputRoute_HDMI`](/documentation/AudioToolbox/kAudioSessionOutputRoute_HDMI)

An output available through the HDMI interface.

[`kAudioSessionOutputRoute_AirPlay`](/documentation/AudioToolbox/kAudioSessionOutputRoute_AirPlay)

An output on an AirPlay device.
