# 来源与知识依据

使用固定 SourceReader/ApiCatalog。官方原文存于 docs-raw/official，查询入口见 `docs/corpus/entrypoints.md`。模型 source_catalog 只能读取自己的平台和完整输入清单；对齐和审查阶段可读取三端资料。

系统 SDK、AndroidX/生态服务、OpenHarmony/HarmonyOS 和 Apple 文档的 iOS 可用性必须分开核实。首版研究范围为系统 SDK 的公开应用开发接口及 Native 接口。

真实 URL 或成功下载本身不足以支持结论。正文摘录必须存在于哈希匹配的快照，条件与结论范围还要经过独立语义审查。来源目录数、已下载数、API 归属数和功能覆盖是不同指标。
