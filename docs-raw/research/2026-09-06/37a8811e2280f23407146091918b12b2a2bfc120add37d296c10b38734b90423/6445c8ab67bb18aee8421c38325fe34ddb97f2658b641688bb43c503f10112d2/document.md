# Device Trust from Android Enterprise - Available signals

**Important:** Access to the device trust signals is restricted using an allowlist
to prevent unauthorized usage. For additional information see:
[**Register for access**](https://developers.google.com/android/management/device-trust-register).

Device Trust from Android Enterprise makes available a set of device posture
signals that registered application can access to compute a trust score of the
device.

For information on how to integrate the Android Management API SDK in your
application see
[Device Trust from Android Enterprise - Integration guide](https://developers.google.com/android/management/device-trust-api).

| Signals | |
| --- | --- |
| OS Version | [`SoftwareInfo`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/SoftwareInfo) includes the OS version of the device. Older OS versions typically have more vulnerabilities. |
| Does the device have pending OTA | [`SoftwareInfo.SystemUpdateInfo`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/SoftwareInfo.SystemUpdateInfo) returns if there is a pending OS update for the device. Proxy for if the device is vulnerable to exploits. |
| Device Security Patch Level | [`SoftwareInfo#getDeviceSecurityPatchInfos()`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/SoftwareInfo#getDeviceSecurityPatchInfos()) returns the current security patch level of the device for different updatable components:  * `SYSTEM` * `KERNEL` * `SYSTEM_MODULES` (also known as Android's   [mainline modules](https://source.android.com/docs/core/ota/modular-system)) |
| Published Security Patch Level | [`SoftwareInfo#getPublishedSecurityPatchInfos()`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/SoftwareInfo#getPublishedSecurityPatchInfos()) returns the current published security patch level of the device for different updatable components:  * `SYSTEM` * `KERNEL` * `SYSTEM_MODULES` (also known as Android's   [mainline modules](https://source.android.com/docs/core/ota/modular-system)) |
| Critical App Details | [`Device#getApplicationReports()`](https://developers.google.com/android/management/reference/amapi/kotlin/com/google/android/managementapi/device/model/Device#getApplicationReports()) returns details on all installed applications to extensibility apps and calling application with role [`COMPANION_APP`](https://developers.google.com/android/management/reference/rest/v1/enterprises.policies#RoleType.ENUM_VALUES.COMPANION_APP) on a managed device. For all other use cases `Device#getApplicationReports()` returns details on the following critical apps:  * `com.android.chrome` * `com.google.android.gms` * `com.google.android.apps.work.clouddpc` * `com.android.vending` * `com.google.android.webview`  The provided details are shared with a list of [`ApplicationReport`](https://developers.google.com/android/management/reference/amapi/kotlin/com/google/android/managementapi/device/model/ApplicationReport). |
| Device Model / Brand | [`HardwareInfo#getModel()`](https://developers.google.com/android/management/reference/amapi/kotlin/com/google/android/managementapi/device/model/HardwareInfo#getModel()) returns the device model and [`HardwareInfo#getBrand()`](https://developers.google.com/android/management/reference/amapi/kotlin/com/google/android/managementapi/device/model/HardwareInfo#getBrand()) returns the device brand. |
| Screen lock complexity | [`DeviceSettings#getScreenLockComplexity()`](https://developers.google.com/android/management/reference/amapi/kotlin/com/google/android/managementapi/device/model/DeviceSettings#getScreenLockComplexity()) returns how complex the current user's screen lock is. [Req. `REQUEST_PASSWORD_COMPLEXITY` permission](https://developer.android.com/reference/android/Manifest.permission#REQUEST_PASSWORD_COMPLEXITY). |
| Management State (and managing app) | [`Device#getManagementMode()`](https://developers.google.com/android/management/reference/amapi/kotlin/com/google/android/managementapi/device/model/Device#getManagementMode()) returns the management state and [`Device#getManagementAppPackageName()`](https://developers.google.com/android/management/reference/amapi/kotlin/com/google/android/managementapi/device/model/Device#getManagementAppPackageName()) returns the management app.  The returned information depends on the profile the application is running in. For details see the [Management state table](https://developers.google.com/android/management/device-trust-signals#management-state). |
| Disk encryption | [`DeviceSettings#getEncryptionStatus()`](https://developers.google.com/android/management/reference/amapi/kotlin/com/google/android/managementapi/device/model/DeviceSettings#getEncryptionStatus()) returns if the device's storage is encrypted. |
| Access Network State (Network state and Wi-Fi state) | You can use [`Device#getNetworkInfo()`](https://developers.google.com/android/management/reference/amapi/kotlin/com/google/android/managementapi/device/model/Device#getNetworkInfo()) to get details about all active networks on the device:  * Network transport (cellular / Wi-Fi) * Wi-Fi Security level   (`OPEN`, `PERSONAL`,   `ENTERPRISE_EAP`, `ENTERPRISE_192`) * Private DNS state  [Req. `ACCESS_NETWORK_STATE` permission](https://developer.android.com/reference/android/Manifest.permission#ACCESS_NETWORK_STATE) |
| Google Play Protect VerifyApps | [`DeviceSettings#getGooglePlayProtectVerifyAppsState()`](https://developers.google.com/android/management/reference/amapi/kotlin/com/google/android/managementapi/device/model/DeviceSettings#getGooglePlayProtectVerifyAppsState()) returns the current `GooglePlayProtectVerifyAppsState`. |
| Is DNS over TLS enabled | [`NetworkParams#getPrivateDnsState()`](https://developers.google.com/android/management/reference/amapi/kotlin/com/google/android/managementapi/device/model/NetworkInfo.NetworkParams#getPrivateDnsState()) returns whether private DNS is used on the network. |
| WebView package | [`SoftwareInfo#getWebviewPackage()`](https://developers.google.com/android/management/reference/amapi/kotlin/com/google/android/managementapi/device/model/SoftwareInfo#getWebviewPackage()) returns the name of the current WebView package. |
| Human-readable business name of the management provider | On AMAPI-managed device, [`ManagementProviderInfo`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/ManagementProviderInfo) can be used to retrieve the human-readable business name of the management provider. This signal is available starting from AMAPI SDK v1.7.0-rc01. |

### Management state

The values returned for the management signals depends on the profile that your
application is running in.

**Key Point:** [`Device.WorkProfileState`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/Device.WorkProfileState) signal is available starting from AMAPI
SDK v1.4.0-rc01.

| Management state | Signals when called from within the Personal Profile | Signals when called from within the Work Profile |
| --- | --- | --- |

| Work Profile on personally-owned device (BYOD) | **ownership:** [`PERSONALLY_OWNED`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/Device.Ownership#PERSONALLY_OWNED)  **managementMode:** [`UNMANAGED`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/Device.ManagementMode#UNMANAGED)  **managementAppPackageName:** `N/A`  **workProfileState:**  * A13+:   [`WORK_PROFILE_PRESENT`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/Device.WorkProfileState#WORK_PROFILE_PRESENT) * A9-12 (AMAPI):   [`WORK_PROFILE_PRESENT`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/Device.WorkProfileState#WORK_PROFILE_PRESENT) * A9-12 (CustomDPC):   [`WORK_PROFILE_STATE_UNSPECIFIED`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/Device.WorkProfileState#WORK_PROFILE_STATE_UNSPECIFIED) | **ownership:** [`PERSONALLY_OWNED`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/Device.Ownership#PERSONALLY_OWNED)  **managementMode:** [`PROFILE_OWNER`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/Device.ManagementMode#PROFILE_OWNER)  **managementAppPackageName:** `Package name of the Profile Owner application`  **workProfileState:**  * A9+:   [`WORK_PROFILE_PRESENT`](https://developers.google.com/android/management/reference/amapi/com/google/android/managementapi/device/model/Device.WorkProfileState#WORK_PROFILE_PRESENT) |
