# 知识置信度与复核范围改造验收

日期：2026-09-05。版本范围仍为启动日各平台最新正式版、手机优先；本次未生产平台事实，也未执行真机测试。

## 已实现

- presence / facts / comparisons 逐项记录高、中、低、未评估四档；人工真机需求独立为必须、建议、无需，缺记录为未评估。
- confirmed 强制有效评级；高可信需要已确认官方证据；中可信也校验正文与版本适用性；未知不允许标成高/中可信。
- 评级随陈述、节点、证据、平台上下文变化失效；实测结果绑定当前陈述及具体测试用例，有可追溯材料与哈希。
- 失败/不确定的实测不能维持高/中可信；缺少计划样本不会变成通过；样本通过不自动升档或外推全部设备。
- 特性树支持组合筛选、叶子/分支、知识项预算、清单预览/复制/下载；完整节点 ID 精确匹配，导航祖先不计入导出范围。
- 命令行导出明确选择数、未选数、节点与知识项 ID；按复核顺序排序，不伪装为统计代表性抽样。
- 详情和检索片段显示评级；矩阵、树视图、审计与预检查接入分级，叶子/分支分开统计。
- 研究规范要求洞察保留最弱关键前提的评级与未完成真机限制，不自动扩大用户所选范围。

## 验证结果

- Python 89 项测试通过，含 16 项分级/真机证据对抗测试。
- JavaScript 14 项测试通过；212 节点共 1,060 个详情面板服务端渲染检查通过。
- 前端生产构建通过；仍有 Ant Design 主包超过 500 kB 的体积警告，不影响本地功能验收。
- Browser 实际验证高可信筛选为空、完整节点 ID 仅命中一个节点、预算 5 时预览 JSON 确为选 5 / 未选 19 / 匹配 24，并检查评级详情与清单布局。
