# android.graphics.pdf

---

[Kotlin](https://developer.android.com/reference/kotlin/android/graphics/pdf/package-summary "View this page in Kotlin")

Contains classes for manipulation of PDF content.

## Classes

|  |  |
| --- | --- |
| [LoadParams](https://developer.android.com/reference/android/graphics/pdf/LoadParams) | Represents a set of parameters to load the PDF document. |
| [LoadParams.Builder](https://developer.android.com/reference/android/graphics/pdf/LoadParams.Builder) | Builder for constructing `LoadParams`. |
| [PdfDocument](https://developer.android.com/reference/android/graphics/pdf/PdfDocument) | This class enables generating a PDF document from native Android content. |
| [PdfDocument.Page](https://developer.android.com/reference/android/graphics/pdf/PdfDocument.Page) | This class represents a PDF document page. |
| [PdfDocument.PageInfo](https://developer.android.com/reference/android/graphics/pdf/PdfDocument.PageInfo) | This class represents meta-data that describes a PDF `Page`. |
| [PdfDocument.PageInfo.Builder](https://developer.android.com/reference/android/graphics/pdf/PdfDocument.PageInfo.Builder) | Builder for creating a `PageInfo`. |
| [PdfRenderer](https://developer.android.com/reference/android/graphics/pdf/PdfRenderer) | This class enables rendering a PDF document and selecting, searching, fast scrolling, annotations, etc. |
| [PdfRenderer.Page](https://developer.android.com/reference/android/graphics/pdf/PdfRenderer.Page) | This class represents a PDF document page for rendering. |
| [PdfRendererPreV](https://developer.android.com/reference/android/graphics/pdf/PdfRendererPreV) | This class enables rendering a PDF document and selecting, searching, fast scrolling, annotations, etc from Android R till Android U. |
| [PdfRendererPreV.Page](https://developer.android.com/reference/android/graphics/pdf/PdfRendererPreV.Page) | This class represents a PDF document page for rendering. |
| [RenderParams](https://developer.android.com/reference/android/graphics/pdf/RenderParams) | Represents a set of parameters that will be used to render a page of the PDF document. |
| [RenderParams.Builder](https://developer.android.com/reference/android/graphics/pdf/RenderParams.Builder) | Builder for constructing `RenderParams`. |
