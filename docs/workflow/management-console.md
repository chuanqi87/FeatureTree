# 管理台

启动 console serve 后进入六个功能区：

- 特性树：正式树或显式候选树、叶子边界、绑定及知识入口。空树和未生产知识有独立状态。
- 来源与 API：快照、声明、官方主题和文档明细；正文按需读取。
- Agent 工作流：固定范围、具名阶段、状态、尝试、实际模型用量、交付件与返工历史。
- 叶子知识：三端结论、能力结果与 API 形态、逐项依据、评级拖低项、版本与研究规划。正式候选和校准样稿分别标识。
- 人工审核：按文章版本逐结论裁决，记录操作人、依据、重研阶段和历史。
- 发布版本：校准确认、领域冻结、候选准备、事务提交、版本报告和回滚。

树列表不预加载全部正文。每次正式请求固定 release_id；候选对象必须通过显式选择查看，不参与正式统计。失效/人工指出错误的知识不进入默认可信筛选；低可信仍可浏览并进入审核。
