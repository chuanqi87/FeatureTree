# Accelerating ray tracing using Metal

Implement ray-traced rendering using GPU-based parallel processing.

## Discussion> Note: This sample code project is associated with WWDC22 session [10105: Maximize your Metal ray tracing performance](https://developer.apple.com/wwdc22/10105/) and WWDC20 session [10012: Discover ray tracing with Metal](https://developer.apple.com/wwdc20/10012/).

### Configure the sample code project

This sample requires the following system and software configuration:

- macOS 11 or later
- iOS 14 or later
- Xcode 12 or later
