# 叶子知识生产

1. 读取固定领域冻结对象。校准模式使用固定候选树，并显式 draft=true。
2. fk-scope 为叶子固定必答问题：三端支持、三组平台对比较、能力结果、API 形态，以及叶子适用的权限、生命周期、设备和限制维度。
3. 三端研究独立读取同一规格，逐题给出支持/有条件支持/不支持/未知、条件、正文证据和缺口。引用必须匹配文档身份、正文哈希及真实摘录。
4. fk-compare 基于已提交的三端结论推导差异。语法不同不等于结果不同，同名接口也不证明相同能力。相同/不支持/不适用需记录检查范围和替代路线。
5. fk-review 独立裁定每个具体结论版本。修订回到事实、规格或比较的责任 Agent。
6. fk-confidence 逐项评级；fk-assemble 确定性计算整体最低档并组装文章。实质断言都保存在 Claim 集合中。
7. 发布用例验证来源、冻结和评级，再准备不可变清单并切换正式指针。低可信进入审核队列。

API 请求、CLI 参数和恢复操作见 `docs/workflow/operations.md`。不运行旧 refresh，不补造知识空壳。树叶尚无知识时展示待生产。
