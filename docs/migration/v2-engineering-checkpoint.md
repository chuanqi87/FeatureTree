## 关键保护行为

- 格式失败、传输失败、资料不足、语义修订分别处理；无完整回答或余额错误不会无限重试。
- 工作单固定执行器、Agent、Schema、规则、模型及来源；变更通过 replan，新旧产物保留来源回执。
- API、主题处置守恒；游标固定快照；来源缺失与正文哈希异常阻断相应检查。
- 完整路线包含有序步骤，替代路线分别计数；partial 路线只能提供下界。
- 正式知识要求验收冻结，自动树扩展要求具体人工校准确认；通用规划入口也执行这些门。
- 必答结论最低档聚合、关键前提上限、旧评级失效、未知低可信、已知错误阻断有测试。
- 人工裁决锁定文章/结论内容，不能覆盖事件元数据；中断后重复提交不会修改已更新文章。
- 发布使用不可变对象与唯一指针；准备/提交间变化、并发 CAS、切指针后中断、幂等及回滚审核保全有测试。
