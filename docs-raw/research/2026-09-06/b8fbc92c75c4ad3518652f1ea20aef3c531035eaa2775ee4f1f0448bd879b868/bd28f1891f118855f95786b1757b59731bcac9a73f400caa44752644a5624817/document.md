# javax.net

Provides classes for networking applications. These classes include
factories for creating sockets. Using socket factories you can encapsulate
socket creation and configuration behavior.


## Classes

|  |  |
| --- | --- |
| [ServerSocketFactory](https://developer.android.com/reference/javax/net/ServerSocketFactory) | This class creates server sockets. |
| [SocketFactory](https://developer.android.com/reference/javax/net/SocketFactory) | This class creates sockets. |
